# Changelog

All notable project changes are documented in this file. The project follows
[Semantic Versioning](https://semver.org/) from version 1.0.0 onward.

## [1.0.0] - 2026-07-21

### Added

- A documented 1.x compatibility policy for the top-level Python API, CLI,
  primary output filenames, and existing CSV columns
- Stable project metadata, repository links, and package classifiers
- A public release-review checklist
- Wheel build and installation checks in the Python 3.10–3.14 CI matrix

### Changed

- Marked the reviewed top-level API as stable
- Updated the project documentation and portfolio summary for the stable
  public release

### Verified

- All unit tests and package dependency checks
- Non-destructive reproduction of all committed reference results
- Input checksums, CSV values, generated Markdown, and figure structure

No experiment method, parameter, reference metric, or scientific conclusion
changed in this release.

## [0.9.0]

- Defined the reviewed top-level Python API and synchronized version metadata
- Added non-destructive reference generation and complete result verification
- Added dedicated API and reproducibility documentation

## [0.8.0]

- Added joint sensitivity evaluation for partial overlap and controlled
  source-outlier contamination
- Added labeled correspondence-composition and outlier-rejection diagnostics

## [0.7.0]

- Added trim-fraction sensitivity across controlled overlap levels
- Added exact correspondence precision, recall, and residual diagnostics

## [0.6.0]

- Added controlled partial-overlap registration evaluation
- Compared all-pairs and fixed-fraction trimmed ICP

## [0.5.0]

- Added cross-experiment summaries and a shared evidence-review schema
- Standardized CLI names and reference-result directories

## [0.4.0]

- Added rigid-registration evaluation with known rotations and translations
- Added transform error and known-correspondence measurements

## [0.3.0]

- Added local PCA normal estimation and neighborhood-size evaluation
- Added analytic-normal accuracy and perturbation-repeatability measurements

## [0.2.0]

- Added controlled labeled outliers and statistical filtering evaluation
- Added detection and clean-geometry preservation metrics

## [0.1.0]

- Added deterministic synthetic and public-data samples
- Added voxel-downsampling evaluation, CSV reporting, figures, CLI, tests, and
  the initial Python-version CI matrix
